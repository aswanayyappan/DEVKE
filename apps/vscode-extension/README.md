# DevReference (UDKE) — Universal Developer Documentation

An offline-first programming documentation explorer and reference library for Visual Studio Code.

## Features
- **12 Master Domains**: Access programming languages, frontend, backend, mobile, databases, authentication, and DevOps documentation.
- **Offline Search**: Instant full-text search powered by embedded SQLite with FTS5 and BM25 ranking.
- **Detailed Reference**: Overview, installation, formal syntax, parameters, return types, and exceptions.
- **Implementation Pipelines**: Step-by-step procedural guides for authentication flows, database setup, and layout architectures.
- **Offline Knowledge Packs**: Download, update, or remove modular technology packs on demand.

## Usage
- Open the **DevReference** tab in the Activity Bar to explore the documentation tree.
- Press `Ctrl+Shift+P` (or `Cmd+Shift+P`) and type `DevReference: Global Documentation Search` to search across all installed documentation.
- Type `DevReference: Manage Offline Documentation Packs` to install or sync additional technology packs.
